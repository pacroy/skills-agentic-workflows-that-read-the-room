## Recent GitHub Changelog highlights

- **Better label management on issues is generally available** — issues and pull requests can now archive labels instead of deleting them, keeping history intact. (Source: github.blog/changelog, Aug 27, 2026)
- **Copilot code review: Resolution reasons and expanded capabilities** — reviewers can now record why a Copilot code review comment was resolved, and the reviewer covers more scenarios. (Source: github.blog/changelog, Aug 27, 2026)
- **Global model policy generally available** — enterprise admins can set a single Copilot model policy that applies across the organization. (Source: github.blog/changelog, Aug 26, 2026)
